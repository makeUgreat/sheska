# Sheska

Sheska는 pnpm monorepo로 구성되어 있다.

## Workspaces

- `apps/api`: NestJS API
- `apps/ui`: React UI
- `apps/obsidian-plugin`: Obsidian plugin

## Documentation

프로젝트 컨벤션은 `docs/ko/`와 `apps/*/docs/ko/` 아래에 한글로 작성한다.

- 루트 컨벤션: `docs/ko/index.md`
- 모노레포 정책: `docs/ko/monorepo.md`
- API 컨벤션: `apps/api/docs/ko/index.md`
- UI 컨벤션: `apps/ui/docs/ko/index.md`

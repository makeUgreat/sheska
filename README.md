# Sheska

Sheska is organized as a pnpm monorepo.

## Workspaces

- `apps/api`: NestJS API
- `apps/ui`: React UI
- `apps/obsidian-plugin`: Obsidian plugin
- `packages/contract`: HTTP contract shared by the API and its clients

## Documentation

Project conventions are written in Korean. Start from [`AGENTS.md`](AGENTS.md), which links every convention entry point.
